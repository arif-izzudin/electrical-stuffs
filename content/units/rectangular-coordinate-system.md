## Key formulas

- Position vector of a point $P(x, y, z)$:
  $\mathbf{r}_{OP} = x\,\mathbf{a}_x + y\,\mathbf{a}_y + z\,\mathbf{a}_z$
- Magnitude (distance from the origin):
  $\left\| \mathbf{r}_{OP} \right\| = \sqrt{x^2 + y^2 + z^2}$
- Unit vector (direction): $\mathbf{a}_A = \mathbf{A} / \left\| \mathbf{A} \right\|$
- Distance between two points:
  $d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}$
- Right-handed system: $\mathbf{a}_x \times \mathbf{a}_y = \mathbf{a}_z$

## Quick answers

- **How do you find the position vector of a point?** Attach the coordinates to the unit
  vectors: for $P(x, y, z)$, $\mathbf{r}_{OP} = x\,\mathbf{a}_x + y\,\mathbf{a}_y +
  z\,\mathbf{a}_z$; the vector always starts at the origin.
- **How do you calculate the magnitude of a vector?** Square-root of the sum of squared
  components: $\sqrt{A_x^2 + A_y^2 + A_z^2}$ (Pythagorean theorem).
- **What is the unit vector formula?** Divide the vector by its magnitude:
  $\mathbf{A} / \left\| \mathbf{A} \right\|$; e.g. for $\mathbf{r} = 3\,\mathbf{a}_x +
  4\,\mathbf{a}_y$, the unit vector is $0.6\,\mathbf{a}_x + 0.8\,\mathbf{a}_y$.
- **Are $\mathbf{i}, \mathbf{j}, \mathbf{k}$ and
  $\mathbf{a}_x, \mathbf{a}_y, \mathbf{a}_z$ the same?** Yes &mdash; both name the unit
  vectors along $+x$, $+y$, $+z$; subscript notation is standard in electromagnetics.
